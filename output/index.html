postmarketOS 2026-06 月度更新：Plasma 6.7 到来

postmarketOS 6月月度更新发布，重点包括：KDE Plasma Mobile 6.7 进入 Alpine Linux 和 postmarketOS（由 Bart 维护）；社区在 NLUUG 和 Embedded Recipes 等会议上发表演讲；Alpine Linux 正式加入 postmarketOS 会议，成为"postmarketOS 与 Alpine Linux 会议"；新增受信任贡献者 bluebunny 和 Lukas；usb-signaller（Rust 重写的 usb-moded 替代品）合并到 edge 分支，支持事务性模式切换、更清晰的日志、处理缺失内核驱动等；Duranium 系统新增 Waydroid 支持和 systemd/bootctl 回滚机制；多个设备内核更新，包括 LG G7 ThinQ 触摸屏支持；放弃 armhf (armv6) 架构支持。

postmarketOS v26.06 "Alpen Avocado" 正式发布

postmarketOS 启用新版本命名方案，发布 v26.06 "Alpen Avocado"。基于 Alpine Linux 3.24，主要更新：GNOME 50 替代 GNOME 49（移动版保持 48.mobile.0 并获重要修复）；KDE Plasma Mobile 6.6.5 替代 6.5.6；Phosh 0.55.0 替代 0.51.0，集成了原 postmarketOS tweaks 应用到 Phosh Mobile Settings，切换显示管理器从 tinydm 到 greetd/phrog；Sxmo 保持 1.18.1；systemd 261 替代 257；启动动画从 pbsplash 切换到 Plymouth；最低内核版本要求提升至最老 LTS 内核并强制 LLVM 编译；移除未维护设备包到 archived 分类。

CNX Software 2026-07-28

Ubuntu Touch 24.04-2.0 发布：Morph 浏览器升级至 Chromium 134，支持刘海屏与圆角屏

UBports 发布基于 Ubuntu 24.04 的 Ubuntu Touch 24.04-2.0 更新。核心亮点：Morph 浏览器引擎从 Chromium 87 大跨度升级至 Chromium 134，大幅提升网站兼容性；新增 Widevine DRM 安装器（法律灰色地带，用户自担风险）；支持刘海屏和圆角屏幕，已适配 Fairphone 4/5、所有 Volla 设备及多款社区设备；新增截图编辑器（裁剪、旋转、调色），可用户禁用；改进打印支持；更新多项系统组件与安全补丁。
