postmarketOS 2026-06 月度更新：Plasma 6.7 入驻

📅 2026年7月6日 postmarketOS

postmarketOS 六月月度进度报告发布。重点亮点包括：

Plasma 6.7 已经进入 Alpine Linux 和 postmarketOS，由 Bart Ribbers 维护。新版本带来了大量桌面和移动端改进。

组织层面：Alpine Linux 正式加入 postmarketOS 会议，成为"postmarketOS 与 Alpine Linux 会议"；建立了硬件 CI 手机测试设备的申请流程；新增两位受信任贡献者 和两位行为准则团队成员；正在通过欧洲行动主义孵化器建立法人实体。

技术进展：Dylan Van Assche 编写的 usb-signaller（Rust 重写的 usb-moded 替代品）已合并到 edge 分支，支持事务性模式切换、更清晰的日志、处理缺失内核驱动等；Duranium 不可变系统支持通过 sysext 运行 Waydroid；系统更新时保留备用引导加载程序以防更新失败。

postmarketOS v26.06 "Alpen Avocado" 正式发布

📅 2026年6月21日 postmarketOS

postmarketOS v26.06 代号"Alpen Avocado"（阿尔卑斯牛油果）发布，基于 Alpine Linux 3.24。这是新命名方案的首个版本（取代之前的 Friends 风格命名）。

主要 UI 版本更新： GNOME 50（移动版保持 48.mobile.0 并修复崩溃与忙循环）、KDE Plasma Mobile 6.6.5、Phosh 0.55.0（含切换到 greetd/phrog 显示管理器的长期工作完成）、Sxmo 1.18.1。

其他重要变更： systemd 261、启动动画从 pbsplash 迁移到 Plymouth、linux-postmarketos-qcom-sdm845 升级到 7.1 内核（LG G7 ThinQ 触摸屏开始工作）、最低内核版本要求提升到最老的 LTS 且必须用 LLVM 构建、正式移除 armhf (armv6) 架构支持、pmaports 文档重组与稳定分支 MR 规则文档化。

注意：此版本主要面向 Linux 爱好者，尚未达到 Android/iOS 级别的成熟度。

PINE64

PinePhone / PinePhone Pro 完整 3D 模型文件发布

📅 2026年7月25日 PINE64

PineStore 发布了 PinePhone 和 PinePhone Pro 的完整 3D 模型文件（STEP 格式），包含按钮、内部和外部框架——此前仅提供后盖模型。这使得用户可以：

  • 使用 3D 打印机自行维修零部件
  • 创建定制外壳和配件
  • 进行机械设计和改装

社区成员 JF 已经利用该模型 3D 打印了定制后盖并分享照片。PINE64 创始人表示 PinePhone 作为开发平台已完成推动移动 Linux 发展的使命，PinePhone 2 "不在当前计划中"（财务风险大、缺乏合适 SoC），但未完全排除未来可能性。PinePhone / PinePhone Pro 仍被许多移动 Linux 项目支持，是目前最开放的移动 Linux 硬件平台之一。

PINE64 5月快讯：PineVoice 量产、PineTime Pro 样机到位

📅 2026年5月18日 PINE64

PineVoice Home Assistant 智能音箱（原 PineVox）进入最后阶段，量产开始。将推出包含 PineVoice、Zigbee 适配器、电源和两个 Matter 模块的限量捆绑包，配合任意 SBC 运行本地 Home Assistant 实例。

重要披露：Desktop PinePower V2 当前批次存在 USB-C 电压显示问题

📅 2026年5月12日 PINE64

PINE64 公开披露：当前在售的 Desktop PinePower V2 批次存在问题——在某些情况下 USB-C 端口会显示 "0V" 即使有设备连接。实际输出电压正常，只是检测电路报告错误。已为后续批次修复，但当前批次无法通过软件修复（MCU 仅能在工厂刷写）。无固定时间表说明修复版本何时上架。官方强烈建议用户不要自行拆开 PinePower 设备（高压电源，存在严重安全风险）。

Phosh 0.56.0 发布：顶栏负载插件、不可变发行版应用隐藏、锁屏旋转支持

📅 2026年7月5日 Phosh

Phosh 0.56.0 主要版本发布，六周发布周期的常规更新。核心组件变更：

phosh 0.56.0： 新增顶栏负载仪表插件；支持在不使用 GNOME Software 的不可变发行版（如 postmarketOS Duranium、BengalOS）中隐藏基础镜像预装应用；启动通知优化（跟踪 fork 进程给予更多启动时间、自动去引号修复误报慢启动）；蓝牙快捷设置在输出变更时不再意外禁用；支持平板锁屏旋转；立即应用刘海/挖孔配置变更；锁屏样式改进；多项崩溃和内存泄漏修复。

phoc 0.56.0 (Wayland 合成器)： 更新到 wlroots 0.20.1；新增 xdg-toplevel-tag-v1 协议支持。

stevia 0.56.0 (屏幕键盘)： 支持按应用指定默认布局（如 Emacs 自动用终端布局）；快捷栏非修饰键启用长按重复；默认添加光标键；切换到 ext-data-control-v1 处理粘贴；更新格鲁吉亚语布局。

phosh-mobile-settings 0.56.0： 新增 os-updates 面板支持 systemd-sysupdate 原子系统更新（不可变发行版）；侧边栏改用 AdwSidebar；about 面板显示镜像版本；概览面板允许重新启用隐藏应用；支持 NexDock 2025；libpms 支持按当前区域添加键盘布局。

KDE Plasma Mobile

KDE Plasma 6.7 发布：每屏虚拟桌面、麦克风音量测试、长按输入特殊字符

📅 2026年6月16日 KDE Plasma

KDE Plasma 6.7 发布，带来多项重量级新功能，同时也适用于 Plasma Mobile：

每屏虚拟桌面：期待 21 年的功能终于到来，每个显示器现在可以有独立的虚拟桌面集合。

麦克风音量测试：系统设置中新增麦克风音量实时测试，不再需要猜测音量是否合适。

虚拟键盘长按输入特殊字符：启用 Plasma 虚拟键盘后，长按按键可输入相关特殊字符（如长按 'e' 输入 é、è、ê 等）。

其他亮点： 亮/暗主题快速切换开关；越南农历日历支持；系统托盘显示 "后台应用"（Flatpak 常用）；打印队列徽章显示活动任务数；Windows 网络共享打印机连接大幅简化；新打印队列管理工具；性能优化和大量 Bug 修复。

Plasma Mobile 6.7 同步获得上述桌面端改进，postmarketOS v26.06 已打包 Plasma Mobile 6.6.5，后续版本将更新到 6.7。
