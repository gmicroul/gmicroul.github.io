postmarketOS

Alpine Linux 基础 · 面向移动设备的长周期发行版

2026年7月6日

postmarketOS in 2026-06: Plasma 6.7 发布与生态进展

postmarketOS 2026年6月月度更新：Plasma 6.7 正式进入 Alpine Linux 与 postmarketOS，由 Bart Ribbers 维护。新增 usb-signaller（Rust 重写的 USB gadget 守护进程，替代 usb-moded，支持事务性模式切换、清晰日志、OpenRC 原生支持），Duranium 支持通过 sysext 运行 Waydroid，EFI 设备新增 systemd/bootctl 回滚引导保护。移除 armhf (armv6) 架构，最低内核版本要求提升至最老 LTS 且必须用 LLVM 编译。Alpine Linux 正式加入 postmarketOS 与 Alpine 合办大会（2026年9月25-27日，德国亚琛）。

发布时间：2026-07-06 原文链接 postmarketOS.org 官方博客

postmarketOS v26.06 "Alpen Avocado" 稳定版发布

2026年6月稳定版发布，代号 "Alpen Avocado"。包含 Linux 6.6/6.12 LTS 内核、Plasma Mobile 6.3、Phosh 46、GNOME Mobile 46、Sxmo 最新版。新增对 LG G7 ThinQ (sdm845) 触摸屏支持，大量设备树主线化改进。存档了无人维护的设备包到 archived 分类，改进 MR 审核流程避免维护者失联导致包僵死。

发布时间：2026-06-21 原文链接 postmarketOS.org 官方博客

postmarketOS Edge 移除 armhf (armv6) 架构支持

因社区无人实际使用且维护成本高，postmarketOS edge 分支正式移除 armhf (armv6) 支持（从未进入稳定版）。这一决策将维护精力集中到 armv7/aarch64 主流架构，利于提升整体软件质量与发布效率。

发布时间：2026-06-22 原文链接 postmarketOS.org 官方博客

Mobian Trixie 稳定版发布：基于 Debian 13，启用 GPG 密钥轮换

Mobian 正式发布 Trixie 稳定版（基于 Debian 13 "Trixie"），提供 Phosh 46.0 与 Plasma Mobile 6.3 两种界面，内核统一升级至 6.12 LTS（Librem 5 仍用 6.6）。新增稳定支持设备：PinePhone、PinePhone Pro、PineTab、Librem 5、Pixel 3a/3a XL、OnePlus 6/6T、Pocophone F1。Fairphone 4/5、PineTab 2、SHIFT6mq 等设备提供镜像但关键硬件（WiFi/音频）暂不工作。强烈建议全新刷机而非原地升级；引入 4 个新 GPG 签名密钥（forky/staging/trixie 分仓库各一 + 镜像专用密钥），Bookworm 旧密钥已过期需更新 mobian-archive-keyring 包。

发布时间：2025-10-13 原文链接 blog.mobian.org 官方博客

Mobian GSoC 2025 成果：tweakster 重构迈向通用内核梦想

Google Summer of Code 2025 期间，学生开发者重写了 tweakster 设备适配守护进程：从过度设计的首版重构为基于 Debian 成熟打包体系的新架构——识别设备树 compatible 属性，读取新格式配置，生成并安装设备专用 Debian 包，首次启动时作为 systemd 服务运行一次即退出。解决了 Rust 开发环境搭建、LXC 容器网络、Neovim 配置等一系列工程化挑战，为 Mobian "单一镜像跑遍所有 ARM64 设备" 的目标奠定关键基础设施。

发布时间：2025-08-23 原文链接 blog.mobian.org 官方博客

Mobian 2025 年初状态：Fairphone 4/5、PineTab 2、SHIFT6mq 等新设备镜像即将进入稳定版；通用内核工作持续推进，目标是单一内核镜像覆盖所有设备；Bookworm 稳定版持续接收安全更新；tweakster 重构进入 GSoC 2025 候选项目。

主线 Linux 内核移动设备支持大幅扩展

Linux 6.6/6.12 LTS 与 7.x 主线版本新增/完善：Qualcomm SM8450/SM6375/SC7280、MediaTek MT6765/MT6768/MT6789、Google Tensor G2/G3、Rockchip RK3566/RK3588、Allwinner D1/R528 等 SoC 的完整驱动栈（DRM/KMS、GPU、音频、USB、调制解调器、电源管理）。OnePlus 6/6T (sdm845)、Pixel 3a/3a XL (sdm670)、Fairphone 4/5 (sm6350/qcm6490)、SHIFT6mq、PinePhone Pro (rk3399)、PineTab 2 (rk3566) 均实现"主线内核启动 + 基础外设工作"，postmarketOS/Mobian/Ubuntu Touch 同步受益。

kernel.org / postmarketOS wiki / Mobian wiki

ModemManager / oFono / ofono-ril 调制解调器栈成熟化

ModemManager 1.22+ 完善对 Qualcomm QRTR、MBIM、QMI 协议的并发处理，解决多网卡切换竞态；oFono 1.33+ 引入 5G NR SA/NSA 网络注册状态上报、IMS 语音/视频呼叫控制接口；ofono-ril 适配 Android RIL 硬件抽象层的设备（如 Pixel 系列）实现 VoLTE/VoWiFi 原生拨号。Purism Librem 5 (BM818)、PinePhone (EG25-G)、PinePhone Pro (BM818) 均在主线栈上实现稳定通话/短信/数据。

freedesktop.org / ModemManager GitLab

Waydroid / Anbox Android 兼容层在主线 Linux 手机上可用性提升

Waydroid 基于容器（binder/lxc）运行完整 Android 12/13 容器，在 PinePhone Pro、Pixel 3a、OnePlus 6 等主线内核设备上实现 GPU 加速渲染（virgl/venus/VirtIO-GPU）、音频直通、传感器桥接、摄像头转发。postmarketOS Duranium 通过 `updatectl enable waydroid` 一键启用；Mobian Trixie 预装 waydroid 包；Ubuntu Touch 24.04 更新 Anbox 至 Android 12 基座。仍存已知限制：ARM64-only 应用需翻译层、Google Play Services 依赖 MicroG、硬件视频编解码受限于 vendor blob。

waydro.id / UBports 文档 / postmarketOS wiki

usb-signaller：postmarketOS 主导的 Rust 重写 USB Gadget 守护进程

替代复杂且 Android 偏重的 usb-moded，usb-signaller 以 <2000 行 Rust 实现：Gadget 初始化、事务性模式切换（host↔device）、清晰结构化日志、缺失内核驱动（如充电器）的优雅降级、不依赖特定 sysfs 节点、原生 OpenRC/systemd 单元。v0.3.0 (2026-06-29) 新增 USB 角色切换支持，已合入 postmarketOS edge，计划随 v26.12 进入稳定版。解决 PinePhone 等主线设备长期存在的 USB 充电/数据/OTG 切换不稳定问题。

codeberg.org/DylanVanAssche/usb-signaller
