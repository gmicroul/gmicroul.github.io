CNX Software 📅 2026-07-28

Ubuntu Touch 24.04-2.0 发布：Morph 浏览器升级至 Chromium 134，新增刘海屏/圆角屏支持与打印功能

UBPorts 宣布发布基于 Ubuntu 24.04 的 Ubuntu Touch 24.04-2.0 版本。此次更新带来多项重大改进：

浏览器引擎大幅升级：Morph 浏览器的内核从 Chromium 87 升级至 Chromium 134，跨越约 5 年的更新，大幅提升了网站和 Web 应用的兼容性。

刘海屏与圆角屏支持：新版本可自适应避开前置摄像头区域和圆角边缘，目前已在 Fairphone 4/5、所有 Volla 设备及多款社区维护设备上配置启用。

新增功能：Widevine DRM 安装器（用于流媒体播放）、截图编辑器（裁剪、旋转、调色）、直接打印文档支持、改进的网络指示器、移动数据连接可靠性提升、fscrypt v2 用户数据加密、格鲁吉亚语键盘支持、约 2000 个新增表情符号。

注意：由于系统存储需求增加，官方支持设备列表有所缩减。现支持设备包括：Asus Zenfone Max Pro M1、F(x)tec Pro1 X、Fairphone 4/5、Lenovo Tab M10 HD 2nd Gen、OnePlus Nord N10 5G/N100、Rabbit R1、Sony Xperia X、Volla Phone 系列、Xiaomi Poco X3/X3 NFC/Redmi 9/9 Prime/Redmi Note 9、Zinwa Q25 等。现有用户可通过两步升级（先到 24.04-1.4 再到 24.04-2.0）。

Liliputing 📅 2026-07-27

Ubuntu Touch 迎来重大功能更新：更好支持现代智能手机硬件与 Web 应用

Ubuntu Touch 是在 Canonical 放弃后由 UBPorts 社区志愿者维护的移动端 Linux 发行版。UBPorts 将 24.04-2.0 Beta 定义为“功能更新”，而非常规的错误修复版本，带来了实质性改进：

刘海屏/圆角屏适配：早期版本会忽略这些硬件特征导致 UI 元素被遮挡，新版本可自动调整界面避开“死区”，但需各设备维护者逐个适配启用。

Morph 浏览器现代化：内核从 2020 年的 Chromium 87 升级到 2025 年的 Chromium 134，虽非最新版但已大幅改善现代网站兼容性。

Widevine DRM 支持：新增可选的 Widevine 安装器，使 Netflix 等受保护流媒体内容可在 Morph 中播放。UBPorts 提示此实现“处于法律灰色地带”，非 Google 官方授权。

该更新标志着社区驱动的移动 Linux 在适配现代智能手机硬件形态方面迈出了关键一步。

PINE64 📅 2026-07-25

Pine64 发布 PinePhone/Pro 完整 3D 模型文件：支持自行 3D 打印维修零件与定制外壳

PineStore 正式发布了 PinePhone 与 PinePhone Pro 的完整 3D STEP 文件，包含按键、内部框架与外部外壳等完整组件结构。这与早期仅提供后盖的文件不同，为用户自行维修与定制化开启了完整可能：

维修自主权：用户可通过 3D 打印自行更换损坏的结构件，无需依赖官方备件供应链。

定制化潜力：开发者与爱好者可基于完整模型设计专用外壳、散热改装、模块化扩展件等。

文件获取：STEP 格式直接下载链接，亦可在 Pine64 Wiki 的“PinePhone board information, schematics and certifications”章节获取。

Pine64 创始人表示，PinePhone 始终定位为推动移动 Linux 生态的开发平台，当前重心已转向将 Linux 移植至更廉价、高性能的安卓手机上。PinePhone 2 并非当前计划，但现有设备仍将长期获得多个移动 Linux 项目的支持，依然是最开放的移动 Linux 硬件平台之一。

Purism 📅 2026-07-23

Purism 发布 Librem 16 笔记本 CAD 模型（STEP/FreeCAD），采用 CC BY-SA 4.0 许可

Purism 继续践行硬件开源承诺，发布 Librem 16 笔记本的完整 CAD 模型，提供广泛使用的 STEP 格式与 FreeCAD 源文件。遵循 Creative Commons BY-SA 4.0 许可，用户可自由复制、修改、集成甚至商业使用这些设计：

维修友好设计：Librem 16 底盖与内部组件均采用螺丝固定而非胶水或塑料卡扣，配合售卖备件与公开 CAD，用户可自行更换绝大多数部件。

低门槛定制制造：随着低量原型制造服务普及（CNC、金属 3D 打印等），用户无需模具即可按需生产定制外壳、扩展模块、专用接口等。

延续 Librem 5 传统：此前 Purism 已发布 Librem 5 手机的 CAD 模型，Librem 16 进一步将“用户真正拥有硬件”的理念延伸至笔记本产品线。

此举强化了 Purism “用户主权”硬件哲学：设备属于用户，不应被专有设计锁死。

Purism 📅 2026-07-09

Purism 展望 Librem 16 未来：模块化扩展与用户驱动创新

Purism CTO Jonathon Hall 分享了 Librem 16 发布后的愿景：将笔记本打造为可深度定制的开放硬件平台。核心思路包括：

模块化扩展湾：预留标准化扩展接口，支持用户开发/安装额外存储、专用 I/O、无线模块、FPGA 加速卡等子板。

社区驱动生态：开放 CAD 与接口规范，鼓励第三方厂商与个人开发者创造专用模块（如摄影师专用多卡槽、音频发烧友 DAC 模块、开发者调试探针等）。

维修与升级并重：不仅是更换损坏部件，更支持随技术演进升级关键子系统（主板、散热、屏幕等），延长设备全生命周期价值。

配合 PureOS Crimson 的发布与核心固件 PureBoot 的持续完善，Librem 16 定位为“全球最私密安全的工作站”同时，也致力于成为最开放、可定制的笔记本平台。

Purism 📅 2026-06-30

PureOS Crimson 正式发布：新增 qdl/Waydroid、UEFI 安装修复、Phosh 暗色模式、Librem 5 支持最新 NexDock

PureOS Crimson 在 2026 年 5 月完成发布，为基于 Debian 的纯自由软件发行版带来大量质量改进与新功能，同步上线 PureOS Upgrade 供现有用户无缝升级：

移动/收敛生态增强：打包 qdl（高通 EDL 模式刷机工具，用于 BM818 基带固件更新）与 Waydroid（在 Linux 上运行安卓应用容器），均可直接从 PureOS 仓库安装，便于 Librem 5 用户维护基带与运行安卓应用。

安装器 UEFI 支持恢复：PureOS 安装器重新支持 UEFI 系统，除 PureBoot 固件的 Librem 系列外，亦可安装至其他 x86 硬件。

Librem 5 硬件支持：更新 EC 内核模块（电池充电阈值保护电池寿命），新增最新版 NexDock 支持（Lapdock Kit 随附机型）。

桌面体验：引入 Phosh 暗色模式，并回港适配 Chatty 通讯应用暗色主题；修复 AppStream 元数据，改善 PureOS Store 应用发现。

发布流程：完成 RC 镜像构建测试、pureos.net 官网更新、新出厂设备预装 Crimson、Byzantium 稳定分支推送升级通道。

后续重心转向 PureOS Dawn 的基础奠基，工程效率显著提升。
