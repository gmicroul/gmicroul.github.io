sailfishos / gecko-dev · PR #188

    

      OPEN
      作者:abranson · 更新于 2026-07-27 · 修复 JB#64784
    

    
标题:[sailfishos][egl] 统一 Qt EGL 显示处理并修复 AV1 播放。

    
主要变更:

    
    
      
  • 修复非 hybris 设备上的浏览器渲染:在 Mesa 上使用 Qt 的借用 EGLDisplay 进行直接 EGLImage 交接;当该显示无 ES3 兼容 EGL 配置时强制 WebRender 使用软件路径,同时保留加速 GLES 呈现。
    • 
      
  • 通过 EGL native-buffer 扩展识别 hybris;选用硬件 WebRender 前探测借用的 GLES 3 上下文。
    • 
      
  • AV1 播放修复:禁用 RDD(Remote Data Decoder),因其未在 EmbedLite 中提供,导致 AV1 流回退到软件解码失败。
    • 
    

    
该 PR 是 Sailfish OS 浏览器在索尼 Xperia 等适配设备上播放现代视频格式的关键修复。
