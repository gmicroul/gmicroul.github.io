postmarketOS 2026-07-06

postmarketOS 2026-06 月报：Plasma 6.7 进入、usb-signaller 合并、Duranium 进展

6月月报涵盖 v26.06 发布后的持续进展。KDE Plasma 6.7 经由 Bart Ribbers 维护进入 Alpine 与 postmarketOS。Dylan Van Assche 编写的 Rust 守护进程 usb-signaller 合并入边缘分支，替代 usb-moded，支持事务性模式切换、更清晰日志、OpenRC 支持，后续版本已实现 USB 角色切换。Duranium（不可变系统计划）新增 Waydroid sysext 支持、EFI 回滚引导加载器保护。组织层面：Alpine Linux 加入联合年会、blueblue 与 Lukas 晋升受信贡献者、Ferass 与 Stefan 加入行为准则团队、启动法律实体注册流程。内核方面：SDM845 升级至 7.1、移除 armhf 架构、通用内核包要求最老 LTS 且需 LLVM 构建。

postmarketOS 2026-06-21

postmarketOS v26.06 "Alpen Avocado" 正式发布

基于 Alpine Linux 3.24 的 v26.06 稳定版发布，代号 "Alpen Avocado"（阿尔卑斯牛油果），启用全新发布命名方案。核心更新：GNOME 50（移动版保持 48.mobile.0）、KDE Plasma Mobile 6.6.5、Phosh 0.55.0、Sxmo 1.18.1、systemd 261。重大改进：启动动画从 pbsplash 迁移至 Plymouth、设备振动反馈支持、通用内核包纳入稳定版、Plasma Bigscreen 回归、sudo-rs 替代 doas。新增设备支持：Google Asurada/Cherry/Corsola Chromebook、PINE64 PineNote、Radxa Dragon Q6A。社区类设备 30+ 款，测试类设备 254 款。5 设备因内核过旧降级至测试类。

Phosh 2026-07-01

Phosh 2026-06 开发新闻：0.56 RC1 发布、OS 更新面板、BengalOS 改进

Phosh 第六期 2026 开发进度更新。0.56 版本候选版（RC1）已发布，正式版预计下周末发布。核心改进：Phosh Shell 修复音频设置多端口问题、收藏夹刷新优化、状态图标排序、启动失败消息改进、布局设置变更追踪。Phoc 更新 wlroots 至 0.20.1、新增格鲁吉亚语翻译。Phosh Mobile Settings 重大更新：支持 systemd-sysupdate1 实现 OS 更新、新增更新检查同与抑制器、隐藏应用重新启用对话框、侧边栏改进、OSK 布局按当前语言添加、自适应快捷键对话框。BengalOS 镜像改进。邀请社区参与测试。
