PINE64 2026-07-25

PineStore 发布 PinePhone / PinePhone Pro 完整 3D 模型文件

PineStore 正式发布了 PinePhone 与 PinePhone Pro 的完整 3D 模型文件（STEP 格式），包含按钮、内部框架与外部外壳。此前仅提供后盖模型，此次发布完整装配文件，为用户自行 3D 打印维修零件、制作定制外壳提供了完整基础。社区成员 JF 已基于该模型打印出定制后盖并分享实物照片。PINE64 创始人表示 PinePhone 使命已完成——推动了原本停滞的移动 Linux 生态发展，目前重心转向将 Linux 移植到更廉价、高性能的安卓手机上，PinePhone 2 短期内不会推出，但不排除未来可能性。

Purism 2026-07-23

Purism 发布 Librem 16 CAD 模型（STEP 与 FreeCAD 格式），采用 CC-BY-SA 4.0 许可

Purism CTO Jonathon Hall 宣布发布 Librem 16 笔记本的完整 CAD 模型，提供广泛使用的 STEP 格式与 FreeCAD 源文件，采用 Creative Commons BY-SA 4.0 许可，允许商业用途的复制、修改与集成。这延续了早期为 Librem 5 发布 CAD 文件的传统，体现“硬件属于用户、可维修、可定制”的理念。Librem 16 底壳与内部组件均由螺丝固定而非胶水或卡扣，用户可自行更换大部件。Purism 同时销售备件但不以此盈利，鼓励社区自行制造或定制部件（如增设 SD 卡槽、液冷接口、利用 EC I2C 接口驱动 RGB 灯效等），并邀请用户在社交媒体分享成果（#librem16 #righttorepair）。

postmarketOS 2026-07-06

postmarketOS 2026-06 月度进展：Plasma 6.7 进入边缘版，usb-signaller 合并，Duranium 可靠性推进

6 月 postmarketOS 边缘版引入 KDE Plasma Mobile 6.7（由 Bart 维护）。组织层面：Alpine Linux 正式加入 9 月 postmarketOS 大会，成为“postmarketOS 与 Alpine Linux 大会”；NLnet 资助的 Duranium 项目推进——Waydroid 支持 sysext、EFI 变量回滚机制；引入 Dylan 编写的 Rust 守护进程 usb-signaller 替代 usb-moded，更简洁、支持事务性模式切换、更好处理缺失内核驱动，已实现 USB 角色切换。设备维护：清理无人维护包至 archived 类别，移除 armhf (armv6) 架构，通用内核包进入 v26.06 稳定版。即将出席 DEFCON 34、FOSSY 2026、FrOSCon 2026 等活动。

postmarketOS 2026-06-21

postmarketOS v26.06 “Alpen Avocado” 发布：基于 Alpine 3.24，GNOME 50、Plasma 6.6.5、Phosh 0.55、新启动动画

v26.06 采用全新命名方案（壁纸名 + 水果），基于 Alpine Linux 3.24。核心更新：GNOME 50（移动版停留 48.mobile.0 并修复崩溃/忙循环）、KDE Plasma Mobile 6.6.5、Phosh 0.55.0（集成原 pmOS tweaks 至 Phosh Mobile Settings、切换至 greetd+phrog 显示管理器）、Sxmo 1.18.1、systemd 261。新增 Plymouth 启动动画（三段式 Logo 淡入淡出、支持 ESC 查看日志、自动旋转）、启动震动反馈（辅助无障碍）、通用内核包、Plasma Bigscreen 回归、ModemManager 升级带来小区广播、sudo-rs 替代 doas。社区类设备新增 Google Asurada/Cherry/Corsola Chromebook、PineNote、Radxa Dragon Q6A 等。5 台设备因内核过旧/无人维护降级至 testing 类别。

Purism 2026-06-30

PureOS Crimson 正式发布：Waydroid/qdl 入库、UEFI 安装器修复、Phosh 深色模式、PureOS Dawn (Debian 13) 已启动

PureOS Crimson（基于 Debian 12 Bookworm）完成发布流程：qdl（BM818 调制解调器刷机工具）与 Waydroid（运行安卓应用）进入官方软件仓库；Calamares 安装器恢复 UEFI 支持；Librem EC 内核模块更新（电池充电阈值保护）；支持最新 NexDock 拉普坞；Phosh 与 Chatty 同步引入深色模式；修复 AppStream 元数据使 PureOS Store 正常显示应用。发布后通过 PureOS Upgrade 推送至现有用户，新出厂设备预装 Crimson。下一代 PureOS Dawn 基于 Debian 13 “Trixie”已启动，正回港 Phosh 依赖链底层库（wlroots、cellbroadcastd、gmobile、directx-headers 为 Mesa 构建准备），计划推出 Alpha 版供早期测试。Librem 16 销售收入将直接资助 PureOS 开发。
